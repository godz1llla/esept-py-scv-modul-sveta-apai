#### 7. Бос мәндерді жойыңыз немесе тиісті әдіспен толтырыңыз.
**Қолданылған Pandas әдістері:** `dropna(), fillna()`

```python
cleanData = myData.dropna()
print("dropna() кейінгі өлшем:", cleanData.shape)

filled = myData.copy()
filled["Пайда"] = filled["Пайда"].fillna(filled["Пайда"].mean())
filled["Сатылым көлемі"] = filled["Сатылым көлемі"].fillna(filled["Сатылым көлемі"].median())
print("fillna() кейінгі бос мәндер саны:", filled.isnull().sum().sum())
```

**Нәтиже:**
```text
dropna() кейінгі өлшем: (600, 13)
fillna() кейінгі бос мәндер саны: 0
```

> **Түсіндірме:**  
> • dropna() әдісі құрамында кем дегенде бір бос (NaN) мәні бар жолдарды кестеден толықтай өшіреді.  
> • fillna() әдісі бос ұяшықтарды өшірмей, оларды көрсетілген мәнмен (мысалы, бағанның орташа мәні mean() немесе медианасы median() арқылы) толтырады.  
> CSV бойынша талдау: Бастапқы кестеде бос мәндер болмағандықтан, dropna() қолданғаннан кейін де кесте өлшемі (600, 13) өзгеріссіз қалды, ал fillna() арқылы өңделген көшірмеде де бос мәндер саны 0 болды.

#### 8. Қайталанатын жолдарды анықтап, оларды жойыңыз.
**Қолданылған Pandas әдістері:** `duplicated(), drop_duplicates()`

```python
print("Қайталанатын жолдар саны:", myData.duplicated().sum())
print(myData[myData.duplicated()])

uniqueData = myData.drop_duplicates()
print("Бастапқы өлшем:", myData.shape, "-> Тазаланған өлшем:", uniqueData.shape)
```

**Нәтиже:**
```text
Қайталанатын жолдар саны: 0
Empty DataFrame (Columns: [№, Күні, Өнім атауы, ...], Index: [])
Бастапқы өлшем: (600, 13) -> Тазаланған өлшем: (600, 13)
```

> **Түсіндірме:**  
> • duplicated() әдісі кестедегі толықтай қайталанатын (дубликат) жолдарды іздейді және duplicated().sum() олардың санын шығарады.  
> • drop_duplicates() әдісі қайталанған жолдарды өшіріп, тек бірегей жазбаларды қалдырады.  
> CSV бойынша талдау: Тексеру нәтижесінде қайталанатын жолдар саны 0 болды. drop_duplicates() қолданылғаннан кейін де кестеде барлық 600 бірегей жазба сақталды.

## 1. Описание данных в `marketing_data.csv`

Исходный файл `marketing_data.csv` содержит **600 строк** и **13 столбцов** с данными о продажах электроники и рекламных кампаниях в городах Казахстана.

| Столбец | Перевод / Смысл | Тип данных | Примеры значений |
| :--- | :--- | :--- | :--- |
| `№` | Порядковый номер записи | Числовой (`int64`) | `1` .. `600` |
| `Күні` | Дата | Текст (`str`) | `01.09.2026`, `02.09.2026` |
| `Өнім атауы` | Название товара | Категория (`str`) | `Телефон`, `Ноутбук`, `Құлаққап` (наушники), `Планшет` |
| `Қала` | Город | Категория (`str`) | `Алматы`, `Астана`, `Шымкент`, `Қызылорда` |
| `Жарнама түрі` | Рекламный канал | Категория (`str`) | `Instagram`, `TikTok`, `Google` |
| `Жарнама шығыны` | Расходы на рекламу | Числовой (`int64`) | `32`, `50`, `80` |
| `Көрілім` | Просмотры / показы рекламы | Числовой (`int64`) | `3327`, `5200`, `7500` |
| `Клиент саны` | Количество клиентов (лидов) | Числовой (`int64`) | `51`, `84`, `110` |
| `Тапсырыс саны` | Количество заказов | Числовой (`int64`) | `22`, `45`, `61` |
| `Сатылым көлемі` | Объём продаж (выручка) | Числовой (`int64`) | `234`, `420`, `620` |
| `Төлем түрі` | Способ оплаты | Категория (`str`) | `Kaspi`, `Halyk` |
| `Менеджер` | Имя менеджера | Категория (`str`) | `Айдана`, `Данияр`, `Аружан` |
| `Пайда` | Чистая прибыль | Числовой (`int64`) | `48`, `120`, `185` |

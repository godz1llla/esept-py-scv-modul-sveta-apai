# Әр тапсырманы жеке-жеке іске қосу нұсқаулығы (Инструкция по запуску каждой задачи отдельно)

**Орындаған:** Орынбеков Губайдулла | **Тобы:** Инф-23-1

Бұл `tasks/` папкасында **20 тапсырманың әрқайсысы жеке Python файлы (`task_01.py` – `task_20.py`)** ретінде сақталған. Егер мұғалім сабақта *«7-тапсырманы немесе 12-тапсырманы жеке қосып көрсетші»* десе, оны 3 түрлі ең оңай жолмен бірден іске қоса аласыз:

---

## 1-әдіс (Ең оңайы): Редакторда (VS Code / Cursor / PyCharm) `Run ▶` батырмасын басу

1. Сол жақтағы файлдар тізімінен `tasks/` папкасын ашыңыз.
2. Мұғалім сұраған тапсырма файлын таңдаңыз (мысалы, `task_05.py` немесе `task_12.py`).
3. Жоғарғы оң жақ бұрыштағы **▶ (Run Python File)** батырмасын басыңыз.
4. Терминалда бірден:
   - Тапсырманың шарты мен Pandas әдістері,
   - Кестенің барлық 12 бағаны (`students_data.csv`) қиылмай толық көрінетін нәтижесі,
   - Қазақ тіліндегі дайын түсіндірмесі (`Түсіндірме`) шығады!

---

## 2-әдіс (Интерактивті мәзір арқылы): Тек тапсырма нөмірін (`1`–`20`) теру

Терминалда мына команданы іске қосыңыз:

```bash
.venv/bin/python tasks/menu.py
```

Экранға барлық 20 тапсырманың тізімі шығады. Сол жерде мұғалім айтқан санды (мысалы, `14` немесе `20`) теріп, `Enter` бассаңыз — сол тапсырма бірден орындалады!

## 4-әдіс: Jupyter Notebook (`students_analysis.ipynb`) ішінде іске қосу

Егер мұғалім Jupyter Notebook-та көрсетуді сұраса:
1. Негізгі папкадағы `students_analysis.ipynb` файлын ашыңыз.
2. Онда әр тапсырма жеке ұяшыққа (cell) бөлінген — кез келген ұяшықтың сол жағындағы **▶ (Run Cell)** батырмасын бассаңыз, нәтижесі дәл сол ұяшықтың астына таблица болып шығады.

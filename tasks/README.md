### Задача 1 (`tasks/task_01.py`)
- **Условие (Қаз):** 1. Өзіңіздің CSV файлыңызды жүктеп, алғашқы 10 жолын экранға шығарыңыз.
- **Условие (Рус):** 1. Загрузить свой CSV-файл и вывести первые 10 строк на экран.
- **Используемые методы Pandas:** `read_csv(), head()`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: pd.read_csv(CSV_PATH) — 'students_data.csv' файлын ашып, оны Python ішіндегі
# DataFrame (электронды кесте) түрінде 'myData' айнымалысына сақтайды.
# ШАГ 1: pd.read_csv(CSV_PATH) открывает файл 'students_data.csv' и превращает его
# в таблицу Pandas (DataFrame), которую мы называем 'myData'.
myData = pd.read_csv(CSV_PATH)

# 2-ҚАДАМ: myData.head(10) — кестенің ең басындағы алғашқы 10 жолды (0-ден 9-ға дейін) алады,
# ал print(...) соны экранға (терминалға) басып шығарады.
# Егер жақша ішіне сан жазбасақ — myData.head() әдепкі бойынша алғашқы 5 жолды шығарады.
# ШАГ 2: myData.head(10) берет ровно первые 10 строк с начала таблицы (индексы от 0 до 9),
# а print(...) выводит их на экран. (Если написать просто head() без числа — выведет 5 строк).
print(myData.head(10))
```

**Объяснение простыми словами (По-русски):**
1. Что делает read_csv(): Представь, что CSV-файл — это обычная таблица Excel, сохраненная в виде текста через запятую. Команда pd.read_csv() открывает этот файл и загружает его в память Python как удобную таблицу (DataFrame) с именем myData.
2. Что делает head(10): В нашей таблице 600 студентов. Чтобы не выводить все 600 строк сразу и просто посмотреть, как выглядит таблица, метод .head(10) («голова» таблицы) отрезает и показывает только первые 10 строк (от индекса 0 до 9).
3. Почему нумерация с 0: В Python счёт всегда начинается с нуля, поэтому 1-й студент имеет индекс 0, а 10-й студент — индекс 9.

**Мұғалімге жауап (Қазақша түсіндірме):**
• read_csv('students_data.csv') — университет студенттерінің үлгерімі жазылған CSV файлды оқып, Pandas кітапханасының DataFrame (кестелік) құрылымына жүктейді.
• head(10) — жүктелген кестенің ең алғашқы 10 жолын (0-ден 9-ға дейінгі индекстерді) экранға шығарады.
CSV бойынша талдау: Кестеде 12 баған бар екені көрінеді: Студент_ID, Аты_жөні, Факультет, Мамандық, Курс, Қала, Оқу_түрі, Қатысу_пайызы, Аралық_бақылау, Емтихан_балы, GPA және Стипендия.

### Задача 2 (`tasks/task_02.py`)
- **Условие (Қаз):** 2. Жолдар мен бағандардың санын анықтап, баған атауларын шығарыңыз.
- **Условие (Рус):** 2. Определить количество строк и столбцов и вывести названия столбцов.
- **Используемые методы Pandas:** `shape, columns`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: myData.shape — кестенің өлшемін (жолдар_саны, бағандар_саны) түрінде қайтарады: (600, 12).
# Назар аудар: shape соңында жақша () қойылмайды, себебі бұл функция емес, кестенің қасиеті (атрибуты).
# ШАГ 1: myData.shape показывает размер таблицы в виде пары чисел (строки, столбцы): (600, 12).
# Важно: после shape скобки () НЕ ставятся, так как это свойство (атрибут) таблицы, а не метод.
print("Кесте өлшемі (shape):", myData.shape)

# 2-ҚАДАМ: myData.shape[0] — (600, 12) жұбының бірінші санын (индекс 0), яғни жолдар санын (600) алады.
# ШАГ 2: myData.shape[0] берет первое число из пары (600, 12) — то есть количество строк (600 студентов).
print("Жолдар саны:", myData.shape[0])

# 3-ҚАДАМ: myData.shape[1] — (600, 12) жұбының екінші санын (индекс 1), яғни бағандар санын (12) алады.
# ШАГ 3: myData.shape[1] берет второе число из пары (600, 12) — то есть количество столбцов (12).
print("Бағандар саны:", myData.shape[1])

# 4-ҚАДАМ: myData.columns — кестенің барлық баған атауларын алады, ал .tolist() оны қарапайым
# Python тізіміне ['Студент_ID', 'Аты_жөні', ...] айналдырады.
# ШАГ 4: myData.columns хранит названия всех столбцов, а .tolist() превращает их в красивый список Python.
print("Баған атаулары:", myData.columns.tolist())
```

**Объяснение простыми словами (По-русски):**
1. Что такое .shape: В переводе с английского shape — это «форма/размер». Возвращает два числа в скобках: (600, 12). Первое число (shape[0] = 600) — сколько строк (студентов), второе число (shape[1] = 12) — сколько столбцов.
2. Что такое .columns: Это свойство хранит «шапку» таблицы (названия всех 12 столбцов). Метод .tolist() мы добавили для красоты, чтобы вывести названия как обычный список Python в квадратных скобках [...].

**Мұғалімге жауап (Қазақша түсіндірме):**
• shape — DataFrame өлшемін (жолдар_саны, бағандар_саны) кортежі ретінде қайтарады: (600, 12).
• columns — кестедегі барлық 12 бағанның атауларын қайтарады, ал tolist() әдісі оларды Python тізімі ретінде шығарады.

### Задача 3 (`tasks/task_03.py`)
- **Условие (Қаз):** 3. Деректер типтерін және әр бағандағы бос емес мәндердің санын анықтаңыз.
- **Условие (Рус):** 3. Определить типы данных и количество непустых значений в каждом столбце.
- **Используемые методы Pandas:** `info(), count()`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: myData.info() — кестенің «паспортын» экранға шығарады:
# әр бағанның атын, онда қанша бос емес (non-null) мән бар екенін және деректер типін (int64, float64, str).
# info() өзі экранға шығаратындықтан, оны print() ішіне салудың қажеті жоқ.
# ШАГ 1: myData.info() выводит полную сводку («паспорт») таблицы:
# сколько всего строк, список всех столбцов, сколько в них заполненных ячеек (600 non-null) и тип данных (Dtype).
myData.info()

# 2-ҚАДАМ: Бос жол (\n) тастап, тақырып шығарамыз:
# ШАГ 2: Выводим заголовок с отступом строки (\n):
print("\nӘр бағандағы бос емес мәндер саны:")

# 3-ҚАДАМ: myData.count() — әр бағандағы тек толтырылған (бос емес / NaN емес) ұяшықтарды санайды.
# Бізде барлық бағанда 600 шығады, себебі бірде-бір бос ұяшық жоқ.
```

**Объяснение простыми словами (По-русски):**

   - Non-Null Count: «600 non-null» означает, что все 600 ячеек заполнены (нет пропусков).
   - Dtype (тип данных): int64 — целые числа (Курс, Емтихан_балы, Стипендия), float64 — дробные числа с точкой (GPA), str (или object) — текст (Аты_жөні, Факультет, Қала).
2. Что делает .count(): Просто возвращает количество заполненных ячеек по каждому столбцу (по 600 везде).

**Мұғалімге жауап (Қазақша түсіндірме):**
• info() әдісі кесте туралы толық техникалық мәлімет береді: жазбалар саны (600), бағандар тізімі, бос емес мәндер саны (Non-Null Count) және деректер типі (Dtype).
• count() әдісі әр бағандағы бос емес (NaN емес) мәндер санын жеке есептейді.
CSV бойынша талдау: 6 баған — бүтін сан (int64), 1 баған (GPA) — бөлшек сан (float64), 5 баған — мәтін (str).

### Задача 4 (`tasks/task_04.py`)
- **Условие (Қаз):** 4. Сандық бағандардың негізгі статистикалық сипаттамаларын алыңыз.
- **Условие (Рус):** 4. Получить основные статистические характеристики числовых столбцов.
- **Используемые методы Pandas:** `describe()`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: myData.describe() — кестедегі ТЕК сандық бағандарды (Курс, Қатысу_пайызы, Аралық_бақылау,
# Емтихан_балы, GPA, Стипендия) автоматты түрде тауып, олардың 8 статистикалық көрсеткішін есептейді:
#   count — мәндер саны (600)
#   mean  — орташа арифметикалық мән
#   std   — стандартты ауытқу (орташа мәннен қаншалықты ауытқитыны)
#   min   — ең кіші мән (минимум)
#   25%   — төменгі квартиль (студенттердің 25%-ы осы саннан төмен)
#   50%   — медиана (қатардың дәл ортасындағы мән)
#   75%   — жоғарғы квартиль (студенттердің 75%-ы осы саннан төмен)
#   max   — ең үлкен мән (максимум)
# .round(2) — үтірден кейін тек 2 цифр қалдырып дөңгелектейді (оқуға ыңғайлы болу үшін).
# ШАГ 1: myData.describe() сама выбирает все числовые столбцы и считает для них всю статистику сразу,
# а .round(2) округляет длинные дроби до 2 знаков после запятой.
print(myData.describe().round(2))
```

**Объяснение простыми словами (По-русски):**
1. Что делает .describe(): Это самая мощная команда для быстрого анализа! Одним вызовом она считает сразу 8 показателей для всех числовых столбцов (текстовые столбцы вроде ФИО и Факультета она автоматически пропускает):
   - count: сколько записей (600)
   - mean: среднее значение (например, средний GPA = 2.98, средний балл экзамена = 79.45)
   - std: стандартное отклонение (разброс значений вокруг среднего)
   - min / max: самое маленькое и самое большое значение (GPA от 1.99 до 3.96)
   - 25%, 50%, 75%: квартили (50% — это медиана).
2. Зачем нужен .round(2): Без него числа выводились бы с длинными хвостами после запятой, а с .round(2) — аккуратно до сотых.

**Мұғалімге жауап (Қазақша түсіндірме):**
• describe() әдісі кестедегі барлық сандық бағандар бойынша негізгі статистикалық көрсеткіштерді (count, mean, std, min, 25%, 50%, 75%, max) автоматты түрде есептейді.
CSV бойынша талдау: Орташа сабаққа қатысу — 83.59%, аралық бақылау орташасы — 79.13, емтихан орташасы — 79.45, орташа GPA — 2.98 (1.99-дан 3.96-ға дейін).

### Задача 5 (`tasks/task_05.py`)
- **Условие (Қаз):** 5. Әр бағандағы бірегей мәндердің санын анықтаңыз.
- **Условие (Рус):** 5. Определить количество уникальных значений в каждом столбце.
- **Используемые методы Pandas:** `nunique(), unique()`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: myData.nunique() — (number of unique) әр бағанда НЕШЕ қайталанбайтын (бірегей)
# мән бар екенін санмен шығарады (мысалы: Факультет — 5, Мамандық — 8, Курс — 4, Қала — 6).
# ШАГ 1: myData.nunique() (от англ. Number of Unique) считает, СКОЛЬКО неповторяющихся вариантов
# есть в каждом столбце (например, всего 5 факультетов, 8 специальностей, 6 городов, 2 формы обучения).
print("Әр бағандағы бірегей мәндер саны:")
print(myData.nunique())

# 2-ҚАДАМ: myData["Факультет"].unique() — тек санын емес, сол 5 факультеттің НАҚТЫ АТАУЛАРЫН тізіммен шығарады.
# ШАГ 2: myData["Факультет"].unique() выводит уже не количество, а САМИ НАЗВАНИЯ этих 5 уникальных факультетов.
print("\nФакультеттер:", myData["Факультет"].unique())

# 3-ҚАДАМ: Мамандық бағанындағы 8 бірегей мамандықтың атауын шығарамыз:
# ШАГ 3: Выводим список всех 8 уникальных специальностей:
print("Мамандықтар:", myData["Мамандық"].unique())

# 4-ҚАДАМ: Қала бағанындағы 6 қаланың атауын шығарамыз:
# ШАГ 4: Выводим список всех 6 уникальных городов:
print("Қалалар:", myData["Қала"].unique())

# 5-ҚАДАМ: Оқу_түрі бағанындағы 2 оқу түрін ('Грант', 'Ақылы') шығарамыз:
# ШАГ 5: Выводим варианты формы обучения ('Грант', 'Ақылы'):
print("Оқу түрі:", myData["Оқу_түрі"].unique())
```

**Объяснение простыми словами (По-русски):**
В чем разница между nunique() и unique() (частый вопрос преподавателя!):
1. nunique() (с буквой 'n' в начале = Number) отвечает на вопрос «СКОЛЬКО уникальных вариантов?» и возвращает ЧИСЛО (например, в столбце Факультет — 5, Қала — 6).
2. unique() (без 'n') отвечает на вопрос «КАКИЕ ИМЕННО это варианты?» и возвращает СПИСОК названий (например: ['Алматы', 'Астана', 'Шымкент', 'Қызылорда', 'Ақтөбе', 'Қарағанды']).

**Мұғалімге жауап (Қазақша түсіндірме):**
• nunique() әдісі әр бағанда қанша қайталанбайтын (бірегей) мән бар екенін санайды.
• unique() әдісі таңдалған санаттық бағанның нақты қандай бірегей мәндерден тұратынын массив ретінде шығарады.
CSV бойынша талдау: Университет деректерінде 5 факультет, 8 мамандық, 4 курс (1–4), 6 қала, 2 оқу түрі (Грант, Ақылы) және 3 шәкіртақы деңгейі (0, 41898, 48183 тг) бар.

### Задача 6 (`tasks/task_06.py`)
- **Условие (Қаз):** 6. Бос мәндерді тауып, әр бағандағы олардың санын есептеңіз.
- **Условие (Рус):** 6. Найти пустые значения (пропуски) и подсчитать их количество в каждом столбце.
- **Используемые методы Pandas:** `isnull(), sum()`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: myData.isnull() — кестедегі әрбір ұяшықты тексереді:
# егер ұяшық бос (NaN) болса — True (1), егер ішінде дерек болса — False (0) қайтарады.
# Ал оған .sum() жалғасақ — әр баған бойынша барлық True (1) мәндерін қосып, бос ұяшықтар санын шығарады.
# ШАГ 1: myData.isnull() проверяет каждую ячейку таблицы на пустоту (True = пусто, False = заполнено).
# А .sum() складывает все True (как единички) по каждому столбцу и показывает, сколько пропусков в каждом столбце.
print("Әр бағандағы бос (NaN) мәндер саны:")
print(myData.isnull().sum())

# 2-ҚАДАМ: myData.isnull().sum().sum() — екінші рет .sum() жазу арқылы барлық 12 бағандағы
# бос мәндерді бір-біріне қосып, бүкіл кесте бойынша ЖАЛПЫ бос ұяшықтар санын (0) табамыз.
```

**Объяснение простыми словами (По-русски):**
Как работает связка myData.isnull().sum():
1. Сначала .isnull() проходит по всем 600×12 ячейкам и ставит True там, где ячейка пустая (NaN), и False — где есть данные.
2. В Python логическое значение True равно 1, а False равно 0. Поэтому когда мы вызываем .sum(), Python просто складывает единички по каждому столбцу.
3. В нашей таблице во всех столбцах вышло 0 — значит, таблица идеально чистая, пропущенных данных нет.

```python
# ШАГ 1: Используем метод .loc[] и оператор & (логическое И — все условия должны выполниться одновременно):
#   1) Факультет == 'Ақпараттық технологиялар' И (&)
#   2) Оқу_түрі == 'Грант' И (&)
#   3) GPA > 3.2.
# Важное правило Pandas: каждое условие обязательно берется в круглые скобки (...)!
filter_and = myData.loc[
    (myData["Факультет"] == "Ақпараттық технологиялар") &
    (myData["Оқу_түрі"] == "Грант") &
    (myData["GPA"] > 3.2)
]
print("1) АТ факультетінде грантта оқитын және GPA > 3.2 студенттер саны:", len(filter_and))

# 2-ҚАДАМ: | (НЕМЕСЕ / ИЛИ) операторы арқылы 2 шарттың кемінде біреуі орындалатын жолдарды табамыз:
# Студент Алматы қаласынан НЕМЕСЕ (|) Астана қаласынан болса жеткілікті.
# ШАГ 2: Используем оператор | (логическое ИЛИ — достаточно выполнения хотя бы одного условия):
# Выбираем студентов, которые приехали из Алматы ИЛИ из Астаны.
filter_or = myData.loc[(myData["Қала"] == "Алматы") | (myData["Қала"] == "Астана")]
print("2) Алматы немесе Астана қаласынан келген студенттер саны:", len(filter_or))

# Бірінші фильтрден өткен үздік грант студенттерінің алғашқы 8-ін экранға шығарамыз:
# Выводим первые 8 найденных студентов из первого фильтра:
print(filter_and.head(8))
```

**Объяснение простыми словами (По-русски):**
Главные правила сложной фильтрации в Pandas:
1. Оператор & (И / AND): выбирает строку только тогда, когда ВСЕ условия верны одновременно (и АТ факультет, и Грант, и GPA > 3.2 — нашлось 36 человек).
2. Оператор | (ИЛИ / OR): выбирает строку, если верно ХОТЯ БЫ ОДНО из условий (город Алматы ИЛИ город Астана — нашлось 291 человек).
3. Почему нужны скобки вокруг каждого условия: В Python у знаков & и | приоритет выше, чем у == и >, поэтому без скобок (условие1) & (условие2) Python выдаст ошибку.

**Мұғалімге жауап (Қазақша түсіндірме):**
• loc[] — жолдар мен бағандарды белгіленген логикалық шарттар бойынша іріктеп алу индексаторы.
• & (ЖӘНЕ) операторы барлық шарттардың бір мезгілде орындалуын талап етеді, ал | (НЕМЕСЕ) операторы кемінде бір шарттың орындалуын тексереді.
CSV бойынша талдау: АТ факультетінде грантта оқитын әрі GPA > 3.2 болатын 36 студент табылды. Ал Алматы немесе Астана қалаларынан келген студенттер саны — 291.

### Задача 19 (`tasks/task_19.py`)
- **Условие (Қаз):** 19. Ең жиі кездесетін мәнді анықтаңыз.
- **Условие (Рус):** 19. Определить наиболее часто встречающееся значение (моду и таблицу частот).
- **Используемые методы Pandas:** `mode(), value_counts()`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: Санаттық (мәтіндік) 4 бағанды цикл арқылы кезекпен тексереміз:
# ШАГ 1: Проходим циклом for по 4 главным текстовым столбцам ('Факультет', 'Мамандық', 'Қала', 'Оқу_түрі'):
for col in ["Факультет", "Мамандық", "Қала", "Оқу_түрі"]:
    # 2-ҚАДАМ: myData[col].mode()[0] — осы бағанда ЕҢ КӨП (ең жиі) кездесетін мәнді (моданы) табады.
    # [0] дегеніміз — mode() тізім (Series) қайтаратындықтан, оның ішіндегі бірінші мәнді ғана алу.
    # ШАГ 2: .mode()[0] находит МОДУ — самое популярное (часто встречающееся) значение в столбце.
    print(f"{col} модасы: {myData[col].mode()[0]}")

    # 3-ҚАДАМ: myData[col].value_counts() — осы бағандағы әрбір мәннің нақты НЕШЕ РЕТ кездесетінін
    # санап, ең көбінен ең азына қарай тізіп шығарады.
    # ШАГ 3: .value_counts() считает точное количество студентов для каждого варианта (по убыванию).
    print(myData[col].value_counts())
    print("-" * 40)
```

**Объяснение простыми словами (По-русски):**
1. Что такое мода .mode(): Мода — это самое популярное значение в столбце (от слова «модный»). Например, самый популярный факультет — 'Ақпараттық технологиялар' (209 чел.), самый частый город — 'Алматы' (173 чел.).
2. Что делает .value_counts(): Если .mode() называет только победителя (1-е место), то .value_counts() расписывает полную статистику: сколько именно раз встретилось каждое значение (например: Грант — 371 студент, Ақылы — 229 студентов).

**Мұғалімге жауап (Қазақша түсіндірме):**
• mode() — бағандағы ең жиі кездесетін мәнді (моданы) табады.
• value_counts() — бағандағы әрбір бірегей мәннің қанша рет кездесетінін кему ретімен санап береді.
CSV бойынша талдау: Ең көп студент оқитын факультет — 'Ақпараттық технологиялар' (209 студент), ең танымал мамандық — 'Математика' (97 студент), ең көп студент келген қала — 'Алматы' (173 студент), ал оқу түрі бойынша 'Грант' (371 студент) басым.

### Задача 20 (`tasks/task_20.py`)
- **Условие (Қаз):** 20. Екі немесе бірнеше сандық баған арасындағы корреляцияны зерттеңіз.
- **Условие (Рус):** 20. Исследовать корреляцию (взаимосвязь) между двумя или несколькими числовыми столбцами.
- **Используемые методы Pandas:** `corr()`

**Код с построчным разбором:**
```python
# 1-ҚАДАМ: myData[num_cols].corr() — барлық 6 сандық бағанның бір-бірімен өзара байланысын
# (Пирсон корреляция матрицасын) есептейді.
# Корреляция коэффициенті -1 мен +1 аралығында болады:
#   • +1-ге жақын болса (мысалы, 0.93 немесе 0.85) — күшті ОҢ байланыс (біреуі өссе, екіншісі де өседі).
#   • 0-ге жақын болса (мысалы, 0.04) — байланыс ЖОҚ (біріне-бірі әсер етпейді).
#   • -1-ге жақын болса — ТЕРІС (кері) байланыс (біреуі өссе, екіншісі кемиді).
# ШАГ 1: myData[num_cols].corr() строит таблицу (матрицу) корреляции между всеми числовыми столбцами.
# Коэффициент корреляции показывает силу связи от -1 до +1:
#   • Близко к +1 (например, 0.93 между Емтихан_балы и GPA) — сильная прямая связь: выше экзамен -> выше GPA!
#   • Около 0 (например, 0.04 у Курса) — связи нет (GPA не зависит от того, на каком курсе учится студент).
corr_matrix = myData[num_cols].corr().round(2)

# 2-ҚАДАМ: Корреляция матрицасын экранға шығарамыз:
# ШАГ 2: Выводим матрицу корреляции на экран:
print("Корреляция матрицасы:")
print(corr_matrix)
```

**Объяснение простыми словами (По-русски):**
Что такое корреляция .corr() простыми словами:
Корреляция показывает, зависит ли один показатель от другого (принимает значения от -1 до +1):
1. На диагонали таблицы всегда стоят 1.00 — потому что каждый столбец сам с собой совпадает на 100%.
2. Между 'Емтихан_балы' и 'GPA' корреляция равна 0.93 (93%), а между 'Аралық_бақылау' и 'GPA' — 0.85 (85%). Это очень сильная прямая связь: чем лучше студент сдал рубежку и экзамен, тем выше его GPA.
3. Между 'Қатысу_пайызы' (посещаемостью) и 'GPA' корреляция 0.71 — кто ходит на пары, у того высокий балл.
4. А у столбца 'Курс' со всеми баллами корреляция около 0 (0.04) — значит, успеваемость не зависит от номера курса.

**Мұғалімге жауап (Қазақша түсіндірме):**
• corr() — сандық бағандар арасындағы сызықтық тәуелділікті (Пирсон корреляция коэффициентін, -1-ден +1-ге дейін) есептейді.
CSV бойынша талдау:
  1) Емтихан_балы мен GPA арасында r = 0.93 және Аралық_бақылау мен GPA арасында r = 0.85 — өте күшті оң корреляция бар.
  2) Қатысу_пайызы мен GPA арасында r = 0.71 — сабаққа көп қатысқан студенттердің балы жоғары.
  3) GPA мен Стипендия арасында r = 0.40 — GPA жоғары болған сайын стипендия мөлшері де өседі.
